# F.N.B. Corporation

> F.N.B. Corporation (NYSE: FNB) is a diversified financial services holding company headquartered in Pittsburgh, Pennsylvania, and the parent of First National Bank of Pennsylvania, an FDIC-insured, state-chartered commercial bank (~$50B total assets, ~350 branches across seven states and Washington, D.C.). F.N.B. publishes NO first-party public developer portal or documented API. Consumer-permissioned account, balance and transaction data is reachable only through third-party data aggregators (notably Plaid, which builds to Financial Data Exchange (FDX) standards), not a first-party FNB API surface.

## APIs

- [FNB Consumer Data Access (Aggregator-Only)](https://plaid.com/institutions/fnb/): No first-party FNB API. Consumer-permissioned data for First National Bank of Pennsylvania is available only via third-party aggregators such as Plaid.

## Notes

- No first-party developer portal, API reference, or downloadable OpenAPI/Swagger specification is published by F.N.B. Corporation.
